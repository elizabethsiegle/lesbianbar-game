# Project history

This repository contains the game migrated from `lesbianbar-game/` in
`gh/elizabethsiegle/demos3idkman`.

The original Entire Trail is [Trail #3](https://entire.io/gh/elizabethsiegle/demos3idkman/trails/3).
Its task was to make the N95, cloth, and novelty masks visibly distinct on the
player character. That trail's implementation and verification discussion is
being copied here. The source game commits were `2e60c14` (game baseline) and
`4a107be` (mask rendering fix).

The full Codex session is tracked in Entire. It includes the prompts and tool
calls for the game work and the original trail. The session ID is
`01a0df06-2a77-77b2-a774-b51bcea7c957`.
